/etc/cpk/cpk-server/managed-verification.json, bound by the normal
CPK_MANAGED_VERIFICATION_CONFIGURATION_FILE environment variable.

Input hashes bind the parent public manifest, gateway and sender bytes. Receiver
coordinates must match the parent workspace/runtime/nodes; website must remain
distinct. The sender's gateway reference must equal the selected gateway
document. Core codecs and bootstrap's bounded canonical input codec remain the
representation owners. No test fixture, key/UUID generator, provider, store,
private path or credential input is called by this renderer.

The output deliberately omits workspace_authority. Vale's normal material-plan
projection computes its REAL private_intent_sha256 and setup administration from
the explicit three identities/scopes/capabilities, then calls normal
plan_root_bootstrap with the selected actual driver ID. The pre-projection
document is not an apply-ready plan and does not prove private admission.

using fixture credentials or a fake commitment, substituting child wrapped PG
for the root database, or treating the listening runtime image as the installer.
