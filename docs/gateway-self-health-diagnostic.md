# Gateway self-health diagnostic retirement status

The #221 direct diagnostic is temporary operational machinery. Its source and
tests remain pending the replacement proof required by
[retirement #340](https://github.com/OpenJ92/control-plane-kit-servers/issues/340)
and [public acceptance #342](https://github.com/OpenJ92/control-plane-kit-servers/issues/342).
It is not the maintained post-bootstrap operator workflow.

Use the [public topology client](../products/cpk_server/docs/client.md) for
supported planning, execution and history. The existing public gateway-probe
command and reads cover their declared probe contract; they do not by themselves
prove a replacement for this diagnostic's distinct signed self-health readiness
behavior. That mapping remains explicit in the
[retirement inventory](operational-framework-retirement.md).

The [historical #221 recipe](learning/gateway-self-health-diagnostic-221.md)
preserves the original preparation and uncertainty record. It is not a current
run instruction or evidence that live prerequisites passed. Source retirement
does not authorize deleting retained inputs, authorization history, tunnel,
DNS, token or other installation state.
