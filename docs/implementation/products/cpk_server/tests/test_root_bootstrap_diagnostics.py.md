This suite checks ephemeral closed diagnostic projection and selected numeric
group laws, without running Docker acquisition. Nested stage guards retain the
inner classification, do not continue after failure and leave an unrelated
receipt untouched. CLI projection emits only the fixed hold shape, omitting
arbitrary error text, causes and tampered diagnostic attributes.

A mocked os.open failure yields persist-receipt/unexpected-error without
fabricating files. This covers that injected failure point, not every fsync/
replace boundary or real effect outcome. KeyboardInterrupt and SystemExit
cross both guard and CLI unchanged rather than being relabeled.

Numeric tests use the live witness's independently recorded exact image
account baseline, combine primary/baseline/socket groups and require exact
membership. Missing or extra groups and a different image reference fail.
They exercise comparison against that baseline, not extraction of the image
filesystem, process identity inspection or socket access. A changed candidate
needs an independently established baseline; diagnostics do not replace it.
