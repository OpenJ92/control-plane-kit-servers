Provider seams supply observed Docker image/container/volume state, not a copy of
the initializer or Operations state machine. A valid positive inspection checks
numeric socket-free helper configuration and pending-before-create custody, then
requires original acquisition fields unchanged and only confirmed temporary
resources removed. Unknown cleanup after matching readback retains pending and
refuses redispatch. Foreign data labels or target drift before start refuse
without dispatch. This is controller composition, not real Docker execution.

The storage seam now records the actual writable volume and directory preparation,
writes progress there at helper start and reads only those persisted bytes after
stop. It cannot manufacture an archive independently of the selected mount.
A failed helper exit retains partial schema acknowledgement, helper, all volumes
and pending intent, and refuses another dispatch. Successful cleanup removes the
progress volume with the other exact-owned temporary resources.
