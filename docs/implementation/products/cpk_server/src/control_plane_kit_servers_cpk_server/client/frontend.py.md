# Frontend composition (#243)

Pure owner: CPK client authoring of the reviewed external website interface.
`frontend_product` transforms an explicit immutable image, canonical HTTPS
upstream and port into an ordinary canonical product with content-derived
identity. `compose_frontend_deployment` adds exactly that instance and the
selected existing connector to an explicit nonmanaged runtime and NamedIngress.

There is no process import, network call, credential resolution, provider effect,
bootstrap edit or published image selection. Empty verification is intentionally
unverified readiness. Runtime authority is a placement reference, never a web
process delivery. Connector document bytes must match its current plain contract.

See the product's `docs/frontend-deployment.md` for the example, supported origin
subset, real workspace isolation obligation and live evidence limits. The law
cards and `test_frontend_deployment.py` protect exact material, ports, canonical
roundtrip, invalid-input refusals and authority absence. Future image adoption or
managed health belongs to its explicit owner, not an exception here.
