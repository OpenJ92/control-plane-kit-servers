Maintain with required source receiving values and all three variant contracts.

CPK owns the fixed cpk-control artifact at /etc/cpk/cpk-server/control.json,
profile cpk-control-configuration.v1. Closed UTF-8 JSON is1–65,536 bytes; the opened
NOFOLLOW/NONBLOCK/CLOEXEC descriptor must be regular and is read at most65,537
bytes. Duplicate/unknown keys, malformed identities/declarations and wrong
purpose-typed public snapshots fail with fixed context-free errors. BaseException
is not swallowed. Separate static/health issuers and1–16 admitted Ed25519 public
keys have no implicit default. The immutable value suppresses repr material.
Trusted parent-path integrity and authorized producer delivery remain prerequisites.

The renderer produces a real JSON/0444 ConfigurationArtifact and round-trips it
through admission. The closed CpkSourceVariant factory preserves all four store
requirements and their bindings, http-api HTTP plus mcp MCP-streamable-HTTP
providers on8080, variant runtime/ingress/material-provider environment, PGPASSWORD
reference/intent, health/log capabilities, lifecycle and complete live/ready
verification policies. It adds only the required artifact and NODE_CONTROLLABLE
liveness-only V2 surface on http-api. No variables, readiness probe, descriptor
publication or selected-artifact delivery mechanism is introduced here.
