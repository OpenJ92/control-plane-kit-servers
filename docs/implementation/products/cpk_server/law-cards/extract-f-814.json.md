These six extraction cards connect old block-control test identities to the
hosted HTTP/MCP boundary. They record auth, bounded body admission, shared
services, and closed rejection of unknown operations.

One historical name refers to unconfigured token-free calls; its behavioral
text deliberately strengthens that old fixture law so hosted mutation-capable
operation is not unauthenticated. Another historical name mentions an unknown
active target, while the assigned law now describes unknown boundary
operations. Names retain provenance and must not override their stated
migration interpretation.

The HTTP/MCP suite checks the schema, issue, ordered law IDs and owners, with
separate behavior tests for current dispatch. The cards themselves are not
runtime policy, exhaustive parity proof or permission to execute mutations.
