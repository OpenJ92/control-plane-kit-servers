# Managed connector target boundary

Source: [managed.py](../../../../../../products/cloudflared_connector/src/control_plane_kit_servers_cloudflared_connector/managed.py).

Servers #188 adds one synthesized native-plus-SDK product node. This checkpoint
contains intentionally unimplemented public composition interfaces, not an
operational adapter. Product configuration/artifact and runtime-contract factories
will reuse Core receiving values; the host will reuse the SDK protected routes.
ConnectorHealth owns bounded native observation and stop/native-death checks.
No canonical authority, controller decoder or external provider effect is added.

The initial new-law targets exercise real values and real SDK credentials, native
connection outcome mapping, denial before observation, contention and stop races.
Existing readiness.py and historical Dockerfile/descriptor remain unchanged.
Lifecycle/signal targets and source-image qualification remain outstanding; this
checkpoint cannot demonstrate process supervision or deployable image readiness.
