## Exact interface checkpoint (before target tests)

Trust roots: wrapper prepare validates clean tracked checkout, git HEAD/source tree and workflow run_id/run_attempt decimal positive strings (at most20 digits), records these in context.json {schema:'cpk.managed-release-context.v1',source_commit:hex40,source_tree:hex40,run_id:decimal,attempt:decimal}. Projector receives expected context plus actual source_root. It hashes current managed recipe/controller recipe/witness and independently checks git HEAD/tree/clean state in the wrapper before run/export; projector compares every receipt against that fixed context rather than deriving context from receipts. Synthetic tests provide context and source files without Docker/network effects. producer.exit is separate optional integer0..255, never a context-derived success claim.

Limits: context and individual owner receipts64KiB; build metadata/remote index/platform/config each1MiB; witness.log1MiB, at most128 newline-delimited JSON records each64KiB; depth30, at most20000 JSON values, strings at most8192 characters; exported JSON at most64KiB. Read fixed file names only. Walk every path component with non-following directory handles, final O_NOFOLLOW|O_NONBLOCK + fstat regular-file and size check, bounded read; do not follow receipt/ancestor symlinks. Export directory must be new beneath validated attempt parent; exact filename created exclusively. Unknown files are ignored, never traversed/exported. A missing/truncated recognized file yields section missing/invalid and a categorical unverified output, no raw exception or path.

Recognized inputs:
