Maintain with the packaged gateway image owner.

Inspects installed Core/SDK origins, actual product import and pip check inside
the candidate. Socket-free readiness observes fixed owned-network endpoints,
with bounded bodies/deadline; gateway401 is listener evidence, not a signed
health result. Log inspection preserves retrieval status and rejects secret/JWT
material without returning its value. It implements no signer, custody protocol,
gateway authorization or state machine. Process/exchange/cleanup are separate.
