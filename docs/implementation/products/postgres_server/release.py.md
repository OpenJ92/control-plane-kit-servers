Pure PostgreSQL publication and borrowed-artifact predicates. Selects the exact
repository and source-bound tag, checks private package/version association, and
matches the inspected digest/source/recipe/platform/user/entrypoint/command.
Its CLI reads bounded duplicate-free provider metadata through a network-free
policy container. It owns no credentials, registry writes or runtime effects.
See [artifact procedure](../../../managed-postgres-artifacts.md).

First-publication admission separately parses the bounded included HTTP response
and command exit status from the exact package GET. It accepts the known404
observation only, with duplicate-free valid JSON, without claiming absence.
Post-first-publication policy adds exact repository association to the existing
private package/tag/digest checks. The pure helper grants no effect authorization.
