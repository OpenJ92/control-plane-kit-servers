Maintain with the router receiving ABI and settings/source contracts.

The product owns a closed bounded public configuration document, fixed profile,
path and artifact ID, actual Core target/runtime/declaration and purpose-typed
SDK static/health trust. Its V2 declaration advertises internal liveness only.
Issuer/audience references are bounded ASCII; key sets retain SDK validation.
The regular-file check applies to the opened no-follow/nonblocking descriptor,
with at most 65,537 bytes read. Parsing/rendering errors are fixed, raised outside
active exception handlers and carry no raw data/cause/context. Interruptions
propagate. File parsing is not producer attestation; parent paths/delivery are
trusted composition prerequisites.

The actual ConfigurationArtifact is JSON/0444 with Core-computed digests. The
source contract requires that artifact and preserves active HTTP requirement,
internal8000, environment/lifecycle and historical five-attempt liveness check;
control capability is added only to this source value. Published descriptors and
catalogue stay unchanged. Core1821/Interpreters149 own authorized production and
selected instance-artifact delivery, not this receiver.

RouterSettings moved from server without a shared helper or cross-product import.
Frozen/repr-suppressed values capture target/port, and only None selects ambient
environment. Direct/test ports remain possible; production8000 is enforced by
main. Invalid parsing is normalized without exposing input in error chains.
