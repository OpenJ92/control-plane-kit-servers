# Owning test-cohort admission

Servers #401 extends the existing `test.sh` and Dockerfile.test entrance with a
closed grandparent selector. Default installation and tests keep the accepted
cohort. The grandparent mode archives the committed candidate source plus full
selected Core, Operations, Interpreters and SDK packages; it never executes
package code on the host or shadows those dependencies through PYTHONPATH.

The default controller supplies public third-party dependencies only. All
inherited CPK distributions are removed before the four approved full packages
are installed without dependency resolution or metadata rewriting. Git source
content, imported roots, distribution RECORD/direct-url, MCP version, absent
Secrets distribution and pip consistency are checked before behavior. Product
imports must point to the admitted candidate tree. This is candidate source-test
evidence, not a qualified deployable artifact or installed-client acceptance.

The new public regression uses the same real host and released client fixture.
Its read-only profile requires exactly four reads and refuses direct command
calls without dispatch; existing two-lifespan behavior is reused. Target-red
precedes adding the profile. Managed factory preservation remains a separate
owning composition proof before source acceptance. No runtime or credential
action is part of this test entrance.
