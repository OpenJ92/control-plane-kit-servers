already-built controller/CPK/Secrets/Postgres images, admits the existing exact

pull. Invalid inputs stop before acquisition. No other legacy branch is released.

inside that controller and preserves the fixture's ownership receipt on uncertain
cleanup or any nonzero primary outcome, including private scenario state. Only
normal verified scenario completion permits disposal. It removes only recorded
labeled resources, in dependency order, without
force-removing a running controller. Command-scoped default context selection is
an execution-packet choice, not a global context edit or socket predicate bypass.

no host port is published. This source checkpoint is unvalidated and not a live
release or a claim that the full G scenario has run.
